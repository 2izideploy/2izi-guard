# Responsible disclosure

If you believe you have found a security vulnerability:

1. Do not include real user data or production secrets in a report.
2. Provide affected version(s), reproduction steps, expected vs actual behavior and security impact.
3. Prefer a minimal proof of concept that does not harm third parties.
4. Contact the security address published at `https://2iziguard.com/.well-known/security.txt`.
5. Please allow the maintainers reasonable time to investigate and coordinate a fix before public disclosure.

This document is a process description, not a bug bounty promise.
