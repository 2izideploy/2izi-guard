# Contributing to 2IZI Guard

2IZI Guard is a security-sensitive project. Contributions are welcome after the public contribution policy is enabled by the maintainers.

## Before submitting a change

1. Do not include production secrets, logs, database dumps, tokens, sessions or user data.
2. Run the complete test suite documented in `README.md` / `tests/`.
3. Security-relevant changes must include or update regression coverage.
4. Treat the implementation as public: never introduce a control whose security depends on hidden JavaScript, field names, undocumented endpoints or obscurity.
5. Keep visitor-facing UI accessible, localized and responsive.

## Security vulnerabilities

Do not open a public issue for an exploitable vulnerability before coordinated disclosure. Follow `SECURITY.md` and use the security contact published by the project.
